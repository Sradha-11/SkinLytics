About Project

"AI Skin Care Suggestion Tool"

This project uses AI to analyze skin conditions from images, videos, and user input to provide personalized skincare suggestions and recommendations.

Purpose of the System

  • Help users understand their skin condition
  • Provide instant AI-based skincare guidance
  • Suggest suitable products and routines
  • Make skincare easy and accessible for everyone

Key Features

  • AI Skin Analysis (Image / Video)
  • Skin Health Score
  • Personalized Skincare Tips
  • Product Recommendations
  • AI Skin Assistant (Chat + Voice + Camera)

Our Mission

"To simplify skincare using intelligent AI solutions and make personalized skin care accessible to everyone."

Technologies Used

  • HTML, CSS, JavaScript
  • AI Integration (Teachable Machine / APIs)
  • Figma (UI Design)

Future Scope

  • More accurate AI models
  • Mobile application
  • Personalized skincare tracking

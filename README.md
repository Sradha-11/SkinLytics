# SkinLytics

## Overview

SkinLytics is an AI-powered skincare analysis and recommendation platform developed as an academic project. The application helps users analyze skin conditions through image uploads, camera capture, and AI-based classification. Based on the analysis, users receive personalized skincare insights and recommendations.

The project combines modern web technologies, browser APIs, and machine learning models to provide an interactive and user-friendly skincare assessment experience.

## Project Workflow

1. User Login / Registration
2. Upload Skin Image or Capture Through Camera
3. AI Model Processes the Image
4. Skin Type / Condition is Identified
5. Personalized Suggestions are Displayed
6. Results are Stored Locally for User Reference
